# 个人期末复习助手 · 前端重构开发规划

面向在 Windows 本机使用个人课件、资料和历年试卷复习单门课程（首门课程为《数据库原理》）的学生，在不改动后端业务接口与数据库结构的前提下，重构 `web/` 前端的信息层级、组件结构、证据核对动线与样式体系。

本文记录经评审锁定的重构设计、模块边界、DOM 与测试契约、分步实施任务及验收标准。开发依据限于[知识库索引](index.json)中同时满足 `active` 与 `verified` 的条目：[首版需求](personal-review-requirements.md)、[M2 需求与验收](m2-acceptance.md)、[M3 学习与导出](m3-acceptance.md)、[M4 课程参考视频](m4-acceptance.md)、[M5 个人电脑试用](m5-acceptance.md)。测试设计与交付检查遵循[项目编码规范](../coding-standards/README.md)。

## 1. 现状基线与重构目标

### 1.1 直接保留的现有设计

- **同源托管与本机访问安全边界**：Spring Boot 同源提供前端静态资源，写操作携带 `X-Review-Request: 1` 请求头，`LocalAccess` 过滤器仅允许回环地址访问。
- **轮询收敛与并发防护**：`sessionStorage` 记忆当前选中批次 `selected-job`；批次文件全部进入 `ready` 或 `failed` 后停止轮询；课程分析使用递增 `generation` 序号防止过期响应覆盖；视频检索按 `version` 使用 `AbortController` 隔离轮询；学习状态使用稳定 `topic.id` 与 `revision` 乐观锁检测双窗口 409 冲突，并通过显式 `htmlFor` 绑定笔记输入框。
- **版本化导出契约**：Markdown 下载固定请求 `/api/course/versions/{version}/export`，由后端按快照输出正命中考点与依据，排除零命中项、个人笔记与完成状态。

### 1.2 重点解决的四个问题

1. **新批次处理态与已发布结果混排，切换批次导致复习状态重置**
   - `web/src/main.tsx` 将 `<Analysis key={job} ... />` 绑定在批次下拉框旁，每次切换“处理批次”或提交新批次都会卸载重建整个分析区，丢失当前查看视角与已展开考点。
   - 当前批次的逐文件解析状态排在整个课程分析和参考视频之后，提交新资料后首屏看不到解析进度或单文件重试入口。
   - 仅用弱提示区分“当前批次 / 上次发布的批次”，未标明上次发布属于第几批，也未在 Markdown 导出入口旁标注所下载的版本归属。
2. **从频次统计或参考计划查回原题与教学出处的操作链条割裂**
   - 四个核心视角藏在原生 `<select>`（`查看方式`）中，切换视角会重置考点展开状态。
   - “参考计划”仅显示知识点名称与排序理由，无法原地展开概念说明与真题依据，也无法一键跳去“复习待办”记录笔记。
   - 全部证据均通过新标签页打开单张预览图或无导航 HTML，返回主页面时缺少“刚查看”视觉锚点；后端 `AnalysisApi` 已在 `sources[id]` 中返回 `file`、`role`、`review` 三个字段，但前端类型未消费，未能区分课件与资料出处。
3. **导入区域永久占据首屏，日常复习阶段主次倒置**
   - `web/index.html` 标题仍固定为 `数据库原理 · 资料导入`，三栏上传卡片在已有发布结果后仍常驻展开，反复复习时每次均需大幅向下滚动。
4. **区域语义耦合、视频统计层级文案固化及窄屏与键盘可访问性不足**
   - `<Videos>` 嵌套在 `<section aria-label="课程分析">` 内部并使用 `<h3>`，与章节目录视图下统计章节 `<h3>` 数量的测试选择器耦合。
   - `web/src/Videos.tsx` 对所有推荐项固定显示 `整条视频`，未区分使用单集统计数据的 `合集单集`，且目录后备来源说明与错误提示混排。
   - 缺少统一的 `:focus-visible` 键盘焦点样式、双窗口 409 冲突并列核对框，以及超长中文教务文件名在窄屏与分屏窗口下的防挤压约束。

### 1.3 已锁定的设计决策与默认基线

- **四页签导航栏（已锁定）**：将“查看方式”由 `<select>` 升级为单次点击可达的 `role="tablist"` 四页签栏（`真题频次`、`章节目录`、`参考计划`、`复习待办`，附计数或完成进度徽章，支持键盘方向键切换），同步更新 `m2-tests`～`m5-tests` 中的视图切换定位器，完整保留全部业务断言。
- **双路径原文核对与返回高亮（已锁定）**：保留原证据链接新窗口打开能力，同时新增 `页内对照` 按钮，在桌面端展开右侧粘性（sticky）原文对照栏、窄屏展开底部模态抽屉，并对最近查看的证据项保持高亮标记与展开状态。
- **GSD Quick-Validate 分步闭环与仓库隔离（已锁定）**：按 4 个独立验证任务推进；本地规划目录 `.planning/` 及本地 Agent 工具配置通过 `.git/info/exclude` 与 `commit_docs: false` 排除在业务提交之外。
- **默认技术基线**：`server/` 后端零改动；`web/package.json` 零新增运行时依赖；采用“首次引导展开三栏上传卡、已发布且无草稿时收缩为单行快捷上传条 + 紧凑批次文件条”的自适应工作台；采用护眼浅色纸墨视觉系统。

### 2.1 视觉令牌与排版规范（案头讲义与真题核对台）

- **色彩令牌**：
  - `--bg-desk: #F7F6F2`（低眩光米白纸底）
  - `--bg-sheet: #FFFFFF`（主阅读区与原文对照面板底色）
  - `--ink-primary: #182622`（松烟深墨标题与正文）
  - `--ink-muted: #4A5D56`（批注灰绿辅助说明与章节归属）
  - `--accent-course: #1E5B45`（黛绿主色：主操作、激活页签、已发布版本铭牌）
  - `--warn-ink: #9A4D18`、`--warn-bg: #FDF6EE`（琥珀批注色：未发布新批次处理横幅、待核对标记、409 冲突提示）

### 2.4 响应式排列规则

- **桌面宽屏（`> 960px`）**：未打开页内对照时考点列表单栏舒展排布（容器上限 `1120px`）；点击任一 `页内对照` 时转为“左列表 `58%` + 右侧粘性原文面板 `42%`”并排对照，支持边看扫描原题边在左侧写复习笔记。
- **分屏与平板窄屏（`≤ 960px`）**：点击 `页内对照` 以底部模态抽屉（高度 `72vh`，带半透明遮罩、关闭按钮与 `Esc` 快捷键）弹出，关闭后焦点自动回到原触发按钮。
- **移动窄屏（`≤ 650px`）**：三栏上传卡片改为单列纵向排列；顶栏、批次状态行与页签栏允许自动折行或横向轻滑；长文件名统一启用 `overflow-wrap: anywhere`，右侧角色/状态标签设置 `flex-shrink: 0` 防止被挤出视口。

### 2.5 空状态与故障状态全表

| 状态场景 | 界面表现与保留的核心提示文案 | 可用操作 |
| --- | --- | --- |
| **已有批次但尚未发布分析** | 批次工作区展示各文件就绪情况；课程分析区显示 `请先分析本批资料，生成复习计划和待办。` | 核对文件文本片段、重新识别或重试失败文件、点击 `分析本批资料` |
| **仅教学资料（无有效试卷）** | 版本铭牌与考点摘要均显示 `暂无试卷统计`，列出全部教学知识点；导出位显示 `暂无有效试卷可供导出` | 按章节、参考计划或待办正常学习并保存笔记；从快捷导入条追加试卷后重新分析 |
| **有有效试卷且存在正命中** | 四个页签统一隐藏 0 命中知识点，总数与可见项一致；铭牌附注未考项及其已存笔记保留在库中 | 查看真题频次、核对原页、勾选待办、写笔记、下载版本化 Markdown |
| **有有效试卷但全零命中** | 主区显示 `本批试卷暂无已确认命中的知识点。`；导出位显示 `暂无已确认命中的知识点可导出` | 展开下方 `待核对（N）` 核查模糊题或未归属页，查看批次文件片段或点 `重新识别正文`，补充讲义后重分析 |
| **仅教学资料且未提取出知识点** | 主区显示 `未提取到有依据的知识点。` | 打开批次文件的 `查看文本与来源` 检查 OCR 结果或点击 `重新识别正文` |
| **单文件解析失败 / 轮询断线** | 失败文件展示具体 `reason`；轮询异常显示 `{pollError}，正在重新连接` | 单独点击 `重试此文件`、`下载原件` 检查文件完整性，或点击 `刷新课程` |
| **新批次分析超时或失败（502/504）** | 上方批次卡以警示色展示失败原因；下方已发布版本内容、页签与笔记状态保持不变 | 点击 `分析本批资料` 重试当前批次，或点击 `读取上次结果` 清除错误提示继续复习旧版并导出 |
| **学习记录读取失败 / 保存失败 / 409 冲突** | 读取失败提示 `读取学习记录失败。`；保存失败保留草稿提示 `保存失败，输入已保留，请重试。`；409 冲突提示 `其他页面已更新此项，请核对已保存的笔记后再保存。` 并并列展示已存内容与当前草稿 | 点击 `重试` 或 `保存笔记`；冲突时可点击 `填入已保存内容` 或手动合并草稿后再次点击 `保存笔记` |
| **参考视频检索中 / 失败 / 目录后备** | 独立区域展示 `正在检索参考视频…`、空结果（`暂无匹配视频` / `暂无可推荐的知识点`）、目录后备说明或失败原因（公开关键词搜索成功路径按知识库范围仍属待验） | 点击 `重试视频检索`；视频异常期间章节浏览、待办勾选、笔记保存与 Markdown 下载均可正常使用 |
