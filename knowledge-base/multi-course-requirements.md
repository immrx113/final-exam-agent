# 多课程学习支持 · 需求与验收（M6）

学生在同一个本机期末复习工作台中，可以按学期创建并切换多门课程（例如在保留《数据库原理》的同时，新增《操作系统》《计算机网络》《数据结构》等课程），为每门课独立导入课件、讲义与历年试卷，查看真题频次、先修参考计划、页内原文对照、复习待办笔记、课程化参考视频并下载对应课程的 Markdown 复习文档。

本需求及 M6-01～M6-08 验收范围已经用户确认，登记状态见[知识库索引](index.json)。单门课程内的三区导入、频次排序、零命中隐藏、参考计划、乐观锁待办笔记、页内对照、Markdown 导出边界及 B 站视频排序降级规则，完整沿用已核验的[首版需求](personal-review-requirements.md)、[M2](m2-acceptance.md)、[M3](m3-acceptance.md)、[M4](m4-acceptance.md)、[M5](m5-acceptance.md) 与[前端重构开发规划](frontend-refactor-plan.md)。配套实现细节见[多课程技术方案](multi-course-design.md)。

## 1. 范围与核心目标

1. **同一服务与界面内管理多门课**：无需为每门新课手工新建一套 Docker 容器或修改启动脚本，从浏览器顶栏即可新建课程和切换当前学习课程。
2. **全链路课程数据隔离**：各门课的已上传文件清单、处理批次、已发布分析快照、真题频次统计、学习完成状态与笔记、导出文档及参考视频检索互不串扰；即使两门课存在同名知识点（如《数据库原理》与《操作系统》均考“死锁”），各自的题数统计、勾选进度和学习笔记也严格独立。
3. **纯本地轻量跨课程提取（零外部大模型依赖）**：
   - 《数据库原理》继续保持既有规则与词表精度，历史已存数据、笔记和回归测试零损兼容；
   - 其他新建课程在不依赖外部或本地大语言模型（LLM）的前提下，通过**教学材料结构化标题、排版强调、显式定义、中英缩写/别名括号自举与通用中文向量语义匹配**提取知识点并关联考题，且绝不被《数据库原理》内置核心词表污染。
4. **课程化导出与视频检索**：Markdown 文档标题与下载文件名随当前课程动态生成；B 站参考视频按当前课程名称与优先知识点检索，并按课程名匹配候选目录。

> **非目标（本阶段不做）**：不引入多用户账号权限体系（仍为单人本机回环访问）；不承诺《高等数学》《线性代数》等纯符号公式计算题在未开启公式识别与大模型判题下的隐含定理高召回；不支持跨课程合并知识图谱。

## 2. 功能需求

### 2.1 课程管理与顶栏切换

- **默认课程自动就绪**：首次启动或从 M1～M5 旧库升级后，系统默认存在《数据库原理》课程并自动选中，直接打开页面时的操作路径与单课程版本一致。
- **列出与切换课程**：页面顶栏展示当前课程名称，提供课程切换入口（显示各课程名称，可标注是否有已发布结果）与“新建课程”入口。
- **新建课程校验**：
  - 输入课程名称（去除首尾空白后非空，长度不超过 80 个字符，不含控制字符与路径分隔符 `/`、`\`）；
  - 与已有课程重名时提示冲突（HTTP `409`），不创建重复课程；
  - 创建成功后自动切换至新课程，进入首次三栏导入引导态（展示三步准备提示与三栏上传卡）。
- **前端状态按课隔离**：切换课程时，自动清空上一门课未提交的本地上传草稿、收起已打开的页内原文对照抽屉、加载目标课程的文件列表、批次列表与已发布快照；浏览器 `sessionStorage` 记忆的当前选中批次按课程分别保存，切回原课程时恢复该课上次查看的批次。页面 `<title>` 同步更新为 `{当前课程名} · 个人期末复习助手`。

### 2.2 课程间数据与访问边界隔离

| 资源维度 | 隔离要求 |
| --- | --- |
| **导入文件与批次** | 课程 A 上传的文件和提交的处理批次仅在课程 A 的“已上传文件”和“处理批次”中可见。两门课上传内容完全相同的文件时，底层对象存储可复用原件字节，但业务文件记录、用途与批次归属按课程独立维护。 |
| **分析快照与频次统计** | 点击“分析本批资料”仅汇总本批次（归属当前课程）的教学资料与有效试卷，只更新当前课程的最新已发布版本，不影响其他课程正在阅读的已发布快照。 |
| **同名考点与学习笔记** | 不同课程拥有相同名称的知识点（例如《数据库原理》的“死锁”与《操作系统》的“死锁”）拥有不同的持久知识点标识；在一门课勾选完成或保存笔记，不会出现在另一门课的待办或冲突提示中。 |
| **跨课参数越权防护** | 通过课程 A 的接口路径访问课程 B 的 `file`、`job`、`version` 或 `topic` 资源时，服务端统一返回 `404`，拒绝读取、重试、改写或导出。 |

### 2.3 轻量跨课程知识点提取与真题匹配

在不引入 LLM 的前提下，Python 分析器按课程配置分流：

1. **内置专属词包模式（《数据库原理》）**：完全保留现有的数据库同义词、SQL 子句归一与核心词表规则，确保 M2～M5 既有准确率与全部验收样例结果不变。
2. **通用轻量自举模式（其他新建课程）**：
   - **严禁跨课词表污染**：不再注入《数据库原理》的 `CORE` / `SUBJECTS` / `ALIASES` 词表（避免其他课程试卷出现“视图”“并发控制”“死锁”等词时被数据库规则误捕获）。
   - **从本课教学资料自举术语与别名**：
     - 识别章节标题（`#` / `##` 或 `第X章`）与小节标题（`###` / `####` 及版面解析识别出的 PPT/PDF 标题块），过滤“目录、教学目标、本章小结、例题、习题、思考题、图X、表X”等教学组织噪声词；
     - 识别加粗强调术语、明确定义句（`是指 / 指的是 / 定义为 / 称为 / 是一种 / 是一类` 及带定义谓词的冒号说明），兼容含英文字母、数字及常见学术符号（如 `B+树`、`TCP/IP`、`I/O多路复用`）的术语名；
     - 自动提取教材/课件常见的括号对照同义词与中英缩写（如 `最近最少使用算法（LRU）`、`传输控制协议 (TCP)`、`管程（又称监控器）`），使讲义全称与真题缩写自动归并到同一知识点；
     - 兼容幻灯片“小标题 + 多条项目符号要点”的版式，将紧随标题的解释要点聚合为简要说明，同时保留显式定义句优先覆盖低优先级说明的择优机制。
   - **通用真题切分与匹配**：
     - 保持独立小问计数、依赖小问合并、否定/背景从句剔除、重复卷去重与存疑页归入“待核对”的既有统计口径；
     - 除常规简答提问句式（`什么是 / 解释 / 简述 XX`）外，支持期末卷常见“名词解释”大题下的短词条小题识别；
     - 未直接字面命中的有效考题，在开启 `REVIEW_SEMANTIC=1` 时继续通过本机 `bge-small-zh-v1.5` 向量模型与本课已提取知识点做余弦相似度匹配，证据不足时归入“待核对”。

### 2.4 课程化 Markdown 导出与参考视频

- **Markdown 导出**：仅收录当前课程所选已发布版本中命中题数大于零的知识点；附件下载文件名格式为 `{课程名}-{version}.md`，附件名中的 Windows 不可用字符替换为下划线，页面与正文保留原课程名。正文首行一级标题为 `# {课程名}`，其余字段白名单（排除零命中项、个人笔记与完成状态）保持不变。
- **B 站参考视频**：
  - 公开接口搜索关键词使用 `{当前课程名} {优先知识点名}`；
  - 整套课程标题相关性判断匹配当前课程名称（及可选配置的课程标题别名）；
  - 当公开搜索受限（如 HTTP 412）或无结果时，按当前课程名称读取 `video-catalog.json` 中的候选 BV 列表；若该课程尚未维护候选 BV 目录，状态栏如实展示搜索未完成或暂无匹配视频原因并提供“重试视频检索”按钮，有考点但成功搜索无匹配且无本课目录时也允许手动重试，刷新复用结果，无可检索考点时只显示空态。不影响章节浏览、页内对照、待办笔记与导出。

## 3. 逐项验收条件（M6-01 ～ M6-08）

| 编号 | 操作或输入场景 | 预期可观察结果 | 建议验证层 |
| --- | --- | --- | --- |
| **M6-01 默认课与存量兼容** | 在已有 M5 数据的环境执行迁移（或从空库启动），直接打开首页并运行既有单课程流程 | 默认选中《数据库原理》，顶栏显示当前课程；原有已发布版本、待办勾选、学习笔记均可正常读取；既有 M1～M5 回归测试通过。 | 数据库迁移、接口、端到端 |
| **M6-02 新建课程与校验** | 点击“新建课程”，分别提交空白名称、与《数据库原理》重名的名称、以及新名称《操作系统》 | 空白名称前端拦截或后端返回 `400`；重名返回 `409` 并给出中文提示；创建《操作系统》返回 `201` 并自动切入该课首次导入引导态，`<title>` 更新为含“操作系统”。 | 接口、浏览器页面 |
| **M6-03 非数据库课轻量自举提取** | 在《操作系统》上传含章节标题、PPT 小标题+要点、括号缩写（如 `最近最少使用置换算法（LRU）`）、显式定义（含 `死锁`、`信号量`）的课件/讲义，以及含“名词解释”大题与缩写题（考 `LRU`、`死锁`）的真题卷，同时在试卷无关背景句或数据库词上设干扰 | 准确提取《操作系统》章节与考点；`LRU` 考题自动归并命中 `最近最少使用置换算法` 并计入频次；“名词解释”小题正确命中；教学结构噪声（`目录`、`本章小结`、`例题`）不成为知识点，且不混入《数据库原理》独有核心词。 | Python 单元测试、浏览器端到端 |
| **M6-04 双课独立与同名考点笔记隔离** | 在《数据库原理》和《操作系统》均发布含正命中考点“死锁”的分析版本；在《数据库原理》勾选“死锁”并保存笔记 A，切换到《操作系统》查看“死锁”并保存笔记 B，再切回《数据库原理》 | 两门课的文件列表、批次下拉框、题数统计完全独立；《操作系统》初始看到“死锁”未勾选且笔记为空，保存笔记 B 后切回《数据库原理》，仍显示已勾选与笔记 A，互不覆盖、不误报 409。 | 数据库集成、浏览器端到端 |
| **M6-05 切换课程时的界面状态隔离** | 在《数据库原理》展开某考点的“页内对照”抽屉、选中第 1 批并在待办输入未保存草稿，随后切换到《操作系统》，再切回《数据库原理》 | 切到《操作系统》时页内对照抽屉已关闭、不会残留上一门课的原页预览或报错横幅；切回《数据库原理》时恢复该课记忆的选中批次。 | 浏览器页面 |
| **M6-06 课程化导出与视频检索** | 在《操作系统》点击“下载 Markdown 复习文档”，并在模拟视频源下观察《操作系统》触发的视频检索请求与未配目录时的降级提示 | 下载文件名以 `操作系统-` 开头，文档首行为 `# 操作系统`，仅含《操作系统》正命中考点与依据；视频搜索关键词为 `操作系统 {优先考点}`；模拟搜索返回 412 且目录无该课时显示失败原因与重试入口，不影响笔记与导出。 | 接口、模拟视频源端到端 |
| **M6-07 跨课越权访问防护** | 用课程 A 的 API 前缀请求课程 B 的 `file` 原件、`job` 详情/分析、`version` 学习状态或 Markdown 导出 | 全部返回 HTTP `404`，不泄露课程 B 数据，也不修改课程 B 状态。 | 接口集成测试 |
| **M6-08 重启持久化恢复** | 创建第二门课程、发布分析并保存待办笔记后重启 Java 服务并刷新浏览器 | 课程列表包含两门课，切换至两门课均可完整恢复各自最新发布结果、待办完成状态与笔记内容。 | 集成、重启验收 |
