# M3 学习与导出 · 需求与验收草案

学生打开《数据库原理》的一次已发布分析，能决定先学什么，完成一个知识点，留下自己的解题心得，并下载可供其他应用检索的课程知识与真题依据。阶段边界见 [M2 验收约定](m2-acceptance.md)。笔记归属待办项、默认导出课程知识与真题依据的产品口径见[首版需求](personal-review-requirements.md)。用户已确认导出 Markdown 文档并排除零命中知识点，其余细则待确认。

## 学生看到什么

| 交付项 | 建议行为 |
| --- | --- |
| 参考计划 | 给当前可见知识点安排学习顺序，每点出现一次，每步有一句可核对的理由。默认从高频点开始。若教学资料有明确依据，可先安排当前可见的前置点，并指出它为哪一步做准备。依据不足或前置关系成环时按 M2 顺序回退。无需输入考试日期或每日时长。 |
| 复习待办 | 每个可见知识点一项，保留章节、命中题数、覆盖卷数及原文入口，可勾选和取消。沿用 M2 题数、覆盖卷数、章节顺序的排序，勾选后位置稳定。有有效卷时隐藏零命中项；只有教学材料时按章节顺序列出，并显示“暂无试卷统计”。 |
| 学习笔记 | 每项支持新建、保存、编辑、清空笔记。勾选与笔记独立保存。重新打开课程、重启服务或追加试卷改变排名后，同一标识仍对应原记录。建议暂时隐藏的项保留历史状态，再次可见时恢复；名称变化导致标识不同的项不自动继承。 |
| Markdown 下载 | 从课程页下载一份 UTF-8 Markdown 文档（`.md`）。仅收录所选发布版本中至少有一道已确认真题命中的知识点，按章节分组，每点一个小节。文件带格式版本、课程名、分析版本和有效卷总数。每点独立包含稳定标识、章节、名称、说明、命中题数、覆盖卷数、教学出处和逐题依据。来源保留文件名与页、行、段落或原图定位。个人笔记与完成状态留在课程内。 |

## 实施顺序

1. 先固定样例和预期。复用 M2 三卷样例验证频次顺序，增加一段明确写出先后关系的自制讲义，分别写出计划与待办的预期顺序。两份顺序可独立验收。
2. 复用 Java 已发布分析中的版本、知识点标识、题数与来源，为待办与计划读取可见点，导出时由后端筛选命中题数大于零的项。先贯通一个知识点从展示到保存、重读的路径。MySQL 按课程与知识点标识保存学习状态，分析版本更新时沿用记录。目前标识由课程和点名生成，跨名称合并需另有依据。
3. 实现参考计划与导出。复习顺序由已发布频次和可追溯的前置关系生成；缺少前置证据时，直接说明频次或章节顺序。Markdown 文档由后端按选定发布版本一次生成，只写明确定义的字段。
4. 在现有 React 课程页接入计划、待办、保存反馈和下载。未发布分析时引导先分析；新分析运行中或失败时继续使用页面标明的上次发布版本。视频推荐按既有阶段划分留到 M4。

## 逐项验收

| 编号 | 输入或操作 | 可观察的结果 | 验证层 |
| --- | --- | --- | --- |
| M3-01 | 三份卷中函数依赖命中 4 题、覆盖 1 份，关系代数命中 3 题、覆盖 3 份 | 待办依次显示“4 题 · 1/3 份卷”“3 题 · 3/3 份卷”；点开能核对原题。 | 规则、课程页 |
| M3-02 | 范式判断更高频，讲义明确说明判断前须先求候选键，两点均可见；再移去该依据 | 有依据时计划先学候选键，理由指出它与范式判断的关系；待办仍以范式判断在先。无依据时按频次；若关系成环仍能列完全部可见点，各一次。 | 规则、课程页 |
| M3-03 | 勾选一项，保存“先求候选键，再判断范式”，取消勾选，刷新，再编辑、重启服务及清空 | 勾选状态与最近成功保存的笔记分别恢复；取消勾选保留笔记；清空后重开仍为空。 | 接口、课程页 |
| M3-04 | 保存笔记后追加试卷并发布，使排名改变；再让该点暂时隐藏后重新出现 | 同一标识恢复原状态，其他项无此笔记，当前待办每点只有一条。 | 数据库集成、课程页 |
| M3-05 | 保存时请求失败，随后重试；在两页先后修改同一旧版笔记 | 失败时保留输入并提示重试；重试成功后可读回。旧页面再次保存时提示冲突，已保存内容及待处理文本可供核对。 | 接口、课程页 |
| M3-06 | 在三卷样例中加入一个零命中点，下载并打开 Markdown 文档，按标识逐点对照界面与人工答案 | 文档中只有正命中项，各占一个小节，题数、覆盖卷数、文件名、题号和位置一致，多考点题及独立小问沿用 M2 计数。文件中无笔记、完成状态、存储凭据或本机绝对路径。 | 导出集成、实际下载 |
| M3-07 | 分别打开尚未发布、仅教学资料、有有效卷但全零命中的课程结果 | 未发布时提示先分析。仅教学资料时仍可浏览，导出区提示暂无有效试卷。有有效卷但全零时提示暂无已确认命中的知识点。两种情况均无可下载文档，直接请求导出也不返回附件。 | 规则、接口、课程页 |
| M3-08 | 在已有发布结果上追加资料，分析期间导出，再分别模拟分析失败、发布成功 | 下载内容与点击时所看的版本一致。失败后原笔记仍可读取；切到新版后统计与证据一并切换。 | 集成、课程页 |

验收由实现者执行，至少从实际课程页走通分析、查看理由、勾选、保存、重开、重分析、下载并阅读 Markdown 文档的全流程，回归 M2 排行与原文定位。交付时记录复现步骤、结果、README 变更和 GitHub 发布安全检查。以上为预期结果，待实现后实测。
