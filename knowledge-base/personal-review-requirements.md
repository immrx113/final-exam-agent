# 个人期末复习助手 · 首版需求

首门试用课程为《数据库原理》。学生一次上传一门课的教学资料与历年试卷，先了解课程有哪些知识点，再用真题判断复习重点。学生可以按建议顺序学习，逐项记录进度和心得，也可以把整理后的知识交给其他应用检索。

## 1. 导入资料与定位原文

上传页设置三个独立区域。每个区域支持选择多份文件，并在本区列出文件名。文件用途由学生放入的区域决定，学生可以在开始分析前调整归类，再统一分析本门课的文件。

| 上传区域 | 文件用途 |
| --- | --- |
| 课件 | 上传课堂幻灯片等授课内容，用于梳理章节和提取知识点。 |
| 资料 | 上传教师讲义、复习提纲等补充材料，用于补充知识点和说明。 |
| 试卷 | 上传历年期末试题，用于关联考点、统计命中题数与试卷覆盖数。 |

- 三个区域均支持 PPT/PPTX、PDF、DOC/DOCX、Markdown 和常见图片（例如 JPG、PNG）。例如，PDF 讲义可放入“资料”，同为 PDF 的期末试题可放入“试卷”。
- 提取可读文本，对扫描页、图片进行文字识别。数据库课程常见的 SQL、关系代数表达式、表格和实体联系图可能影响题意。识别存疑时标记具体位置，供学生直接查看原件。例如，下标模糊时，可从该条结果打开对应幻灯片。
- 来源至少包含文件名和可返回的位置。PDF、幻灯片记录页码或页序，图片定位到原图，Markdown 定位到标题或行，Word 优先定位到原页，分页不稳定时定位到段落。展示失败文件和待核对页；已成功识别的内容仍可用于复习。

## 2. 按章节浏览知识图谱

以课程资料的章节目录为骨架，依次展示课程、章节和知识点。点开知识点可看到简要说明、教学资料出处和相关真题。例如，学生可以从“关系数据理论”进入“函数依赖”，查看定义，再回看考过它的题。章节和说明均以本次上传内容为准。

同一概念在讲义与课件中重复出现时合并出处。仅在试卷中发现或无法可靠归章的考点保留题目来源并标记待归类。课程资料中提取到、尚无真题命中的知识点也保留。

## 3. 统计考查频次

以**命中该知识点的题数**表达出现频率，按题数降序排列。在同一行显示**涉及试卷数 / 已纳入统计的试卷数**，点开可核对试卷、题号和原页。

| 统计情形 | 计数规则 |
| --- | --- |
| 同一题反复提到一个概念 | 该知识点在此题计 1 次。只统计解题需要用到的知识点。 |
| 一道综合题考查多个知识点 | 每个命中的知识点各计 1 次。能独立作答且独立编号的小问按小问计，父题不重复计。 |
| 同一份卷多道题考查同一知识点 | 每道题分别计数，涉及试卷数只增加 1。重复导入同一份卷也只统计一次。 |
| 题数相同 | 暂按覆盖试卷数降序，再按课程章节与知识点顺序排列。 |
| 识别存疑或缺少试卷 | 存疑关联列为待核对，单独提示统计范围。没有可用试卷时显示“暂无试卷统计”；有可用试卷且未命中时显示 0 次。 |

## 4. 复习顺序、待办与学习笔记

- **参考计划**给出一组有先后关系的学习任务，每步附一句理由。高频考点优先考虑；若理解它需要基础概念，可先安排基础。例如，若试卷频繁考查范式判断，可以先回顾函数依赖和候选键，再练习判断范式。学生无需填写考试日期或每日时长。
- **待办清单**为每个知识点生成一项，按第 3 节的考查频次排序。每项显示章节、题数、试卷覆盖数和完成状态，支持勾选和取消。
- **学习笔记**附在对应待办项上。学生能够写下心得、修改已保存内容，取消勾选后仍可查看笔记。重新打开课程后恢复进度与笔记；同一知识点因新增试卷而改变排名时，笔记与勾选状态随知识点保留。

## 5. B 站参考视频

首次分析完成后，按课程名和优先复习的知识点检索视频，**整门课合计推荐 1～3 个链接**。先按标题筛选相关视频并去重，再按播放量降序排列；播放量相同时比较点赞数，两者均相同时比较收藏数，数值高者优先。展示视频标题、对应知识点、可取得的指标及可打开的链接。

若候选课程公开列出合集单集或多分 P 的标题，尝试匹配到具体一讲，能定位时直接链接该讲。例如，有课程在选集目录中列出了“2.4关系代数”和“3.4.2连接查询”。此例能验证目录内可看到标题，全站搜索对子标题的覆盖率及稳定的程序化获取方式仍待验证。[B 站《数据库系统概论-基础篇》选集目录](https://www.bilibili.com/video/BV13T4y1f7dn/)

无法获取子标题时，返回相关的独立视频或整套课程，并注明链接指向。分 P 只有整条视频的互动数据时注明统计层级；指标缺失时显示“未取得”，按可比较的指标排序。相关结果不足时按实际数量展示；没有匹配或检索失败时说明原因，学生仍可使用图谱、待办和导出。

## 6. 为外部 RAG 应用导出 JSON

学生可下载一份 UTF-8 JSON。文件带格式版本、课程名和统计范围，每个知识点独立成条。接收方可直接用知识点说明构建检索文本，以章节、频次和来源作为元数据。稳定的知识点标识便于再次导入时更新同一条记录。默认导出课程知识，个人学习笔记留在课程内。

以下为字段约定和虚构示例。页码从 1 开始；无可用试卷时两个命中统计值使用 `null`，有试卷但未命中使用 `0`。

```json
{
  "schema_version": "1.0",
  "course": "数据库原理",
  "exam_paper_count": 2,
  "knowledge_points": [
    {
      "id": "db-fd",
      "chapter": "关系数据理论",
      "name": "函数依赖",
      "text": "在关系模式中，若任意两个元组在属性集 X 上取值相同，它们在属性集 Y 上的取值也必然相同，则称 X 函数决定 Y。",
      "question_count": 2,
      "matched_paper_count": 1,
      "sources": [
        {"file": "示例讲义.pdf", "page": 8}
      ],
      "exam_evidence": [
        {"paper": "示例卷甲", "question": "2", "page": 1},
        {"paper": "示例卷甲", "question": "4", "page": 2}
      ]
    }
  ]
}
```

## 7. 首版验收场景

| 学生操作或输入 | 应观察到的结果 |
| --- | --- |
| 在“课件”区上传幻灯片，在“资料”区上传 PDF 讲义，在“试卷”区上传 PDF 试卷和另一份试卷的扫描图 | 三个区域分别列出所选文件。分析后能从知识点找到课件或讲义出处，只有“试卷”区的考题计入频次；识别存疑处可打开原页或图片。 |
| 两份教学资料都讲函数依赖，另有一个试卷未考的知识点 | 在对应章节看到合并后的函数依赖及两个出处；未考知识点也可查看。 |
| 三份卷中，函数依赖在一份卷出现 4 题，关系代数在三份卷各出现 1 题 | 函数依赖排在前面，显示“4 题 · 1/3 份卷”；关系代数显示“3 题 · 3/3 份卷”。重复导入其中一卷后结果一致。 |
| 查看参考计划并完成一项复习，写下“先求候选键，再判断范式”后重新打开 | 能读到有理由的学习顺序；对应待办仍已勾选，原笔记可以继续编辑。 |
| 完成首次分析，视频目录可读或暂时不可读 | 有可靠子标题时可看到匹配的一讲；目录不可读时仍可给出相关视频。整门课最多 3 个链接。 |
| 下载 JSON 并用标准解析器读取 | 能按章节取出知识点文本，用标识区分知识点；题数、试卷数和证据与界面对应，个人笔记不会随知识库导出。 |
